# Raw conditional monotonicity and approximation-before-tree complexity

AX and AY report prediction quality continuously, without a fixed-MSE veto.
Matrix input, source manifests and numerical integrity remain checked.

## AX: raw response monotonicity

An X-omission contrast can be nonmonotone even when raw response curves are
monotone. AX therefore varies one Ui with the other U fixed and evaluates
raw fitted responses at every recorded X context. It retains AS's all-5000
anchors, 64-neighbor conditional intervals, 17 nodes and poly5/RBF2 sources.

Each X context is normalized independently. Active direction counts,
active total-variation/range pieces and excess variation above a monotone
curve are separate diagnostics, without a tuned mixture. These measure
conditional U shape; they are not relabeled as pure UX-interaction scores.

CR3 completes with zero full-plane criteria. Best is poly5 conditional
monotonicity-excess subject mean at 10% relative activation: 2/6 planes,
baseline rank 16 (both channels). Later datasets are skipped because the
structural signal is weak, not because of MSE. Six slice tests pass,
including independent 1e-200/1e200 context-scale invariance and a complete
raw-response pipeline with no X omission.

## AY: approximate first, then measure UX function rule cost

AY evaluates the verified poly5/RBF2 function fitted to every original WY
row, applies W-only conditional X witnesses, removes pure-U/pure-X means,
then measures the same per-X tree description cost. Every rotation uses
the same frozen fitted function. Raw and fitted banks must exactly match
X probes and anonymous U coordinates. No derivatives, true equations,
original neural weights or saved case rotations enter scoring.

The run order is CR3/C1/C2/C3, both sources in each model. This four-model
source-resolution audit continues despite small grid deviations. It is
complete. Both sources give CR3 6/6, C1 6/6 and C2 5/6 (baseline ranks
1/1/2). C3 is 11/15, rank 5 for poly5 and 12/15, rank 3 for RBF2.
There is no same-source-family four-grid criterion. Every original model
was run with the same function and metric definitions.

AY2 transfers the already frozen AW rotations without reoptimizing them.
The stronger counterexample scores 527 against poly5 baseline 741 (-28.88%)
and RBF2 baseline 739 (-28.69%). The other scores 587/581
(-20.78%/-21.38%). Neither approximation removes this global counterexample.

The complete suite passes 186 tests. A local-polynomial-leaf prototype
passes three mathematical tests but has not been run as a real-data metric;
it is not presented as experimental success.
