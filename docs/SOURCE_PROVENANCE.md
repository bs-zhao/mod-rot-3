# Frozen original implementations and provenance

**Upstream:** `Cognition-Decision-Modeling-Lab/modlearn-rot-2` (main at migration time, Nov 2026). The original C1/C2/C3 generator files, `GeneratedDataset` data writer, original full precheck implementations, binary-choice NP encoder/decoder, and `DiscreteNPTrainer` were copied without changing their mathematical or training implementations. Their paths under `src/modlearn_rot/` were retained for direct comparison.

The only altered upstream registry is `src/modlearn_rot/generators/registry.py`: it now enumerates only C1, C2 and C3 rather than importing unrelated continuous, Choice-RT, CR1, C4 and C5 models.

## CR3 provenance

`reference/s0_cr2_design_recovery.py` is the upstream CR2-4P bank design and CPT prior/logit implementation. `reference/cr3/s0_s1_cr3.py` is the upstream CR3 bank and 500-choice subject generator. No formula, sampler, prior, default random seed, FOSD rule, or stimulus-bank composition was changed. Only the original repository-root relative path lookup changed because the reference scripts now live in `reference/` instead of `experiment/choice/research_based/`.

CR3 requires the original optimized CR2 500-item design as input. If it is not already in `outputs/choice/CR2/s0_design_recovery/`, `baseline/run.py generate --model CR3` calls the original CR2 design script with `--mode design --variants 4 --seed 20261023`, then runs original CR3 design/data generation with seed `20261023` and data seed `20261028`.

CR3 source checksums are written into manifests and checked before training. Exact generated bytes may depend on the versions of NumPy/SciPy used for the original bank optimization; if exact byte reproduction is required, copy the original CR2 design bank (and optionally CR3 bank) into the corresponding ignored `outputs` path and verify the SHA-256 before regenerating subjects. Do not silently substitute a new design.

`reference/cr3/s2_oracle_cr3.py` and its two `functional_role_identifiability` dependencies are also copied verbatim except for the root path correction, enabling the optional original CR3 oracle check. This is distinct from unsupervised rotation.

## Network policy

- Shared `DiscreteNPConfig` and `DiscreteNeuralProcess` (original Set Transformer encoder and MLP decoder).
- Original `DiscreteNPTrainingConfig` and `DiscreteNPTrainer` (Bernoulli cross entropy + beta KL + lambda_sparse L1).
- Original subject splitting and training-context sampling utilities.
- C1/C2/C3 original seed derivation; CR3 retains the upstream `stable_run_seed(seed, 'CR2_4P', 0, repeat)` policy.
- No parameter truth enters NP training or posterior encoding.
- After training, **all** observed trials are used to produce one frozen posterior mean Z per subject, for FIT, VALIDATION and TEST subjects.
- TEST true parameter values are consulted only for post-training descriptive recovery metrics, never for PCA fit or ridge regularization selection.
