# cld-crossfit-v3 — 交叉拟合的题目级 UX / UU 稀疏性：方法、三鸿沟检验与信息量诊断

> 2026-11-15。在冻结 EXP13 的基础上，继续走 UX / UU 作用稀疏性的路线，目标是绕开"神经网络二阶导不还原"。
> 约束不变：无角色检测、无 ICA；EXP13 及其依赖只读导入；T / Oracle / 解析式只用于诊断和事后评价。
> 只做了 CR3（共享 500 题题库）。C1–C3 没有共享题库，本轮未做。

## 结论（先看这里）

**新方法在数学上成立、在现有数据量上不可用；冻结 EXP13 仍是当前最好的方案。**

1. **有一个无角色损失在 CR3 解析场上精确恢复真轴。** 按题目的 UU 支撑计数（`UUI_softL0_10`）加 `UUd_share`，在 logit 和 p 两个通道都是 0.2–0.6°；EXP13 冻结损失在同一解析场上偏 34–55°（MCC .913 / .763）。识别信息全部来自 logit 的真二阶导 σ′·H_η；只用一阶导构成的 σ″·g gᵀ 部分不行（40° 以上）。
2. **这个损失需要的二阶信息，现有的二值选择数据里不够。** 各题的选择概率对 U 的依赖中，一阶部分占 92.7% 的方差，二阶 6.5%，三阶 0.8%。用全部 3500 个训练被试逐题拟合，二阶系数的噪声能量与信号相当（1.08 倍），三阶是 18 倍；折成逐点的 UU 二阶导后，噪声是信号的 6.5–13 倍。Gap 2（真坐标 + 真实选择）全部失败（13–65°），按刺激上下文合并也救不回。
3. **交叉拟合确实有效，但救不了信息量。** 交叉拟合的能量无偏（均值 1.10e-4 对真值 9.0e-5，普通平方是 1.24e-3）。模拟表明：每个被试每题重复 256 次时方法过关（2–4°），64 次时接近（约 10°）；不做交叉拟合的普通平方到 256 次仍基本不过。也就是差约两个数量级的数据。
4. **decoder 的二阶导不还原，是数据不够决定它，而不是估计目标的固有性质。** 把后验平均放到概率尺度上，λ、τ 的自曲率占比只从 .14 / .19 变到 .16 / .22，远不到 decoder 的 .77 / .67。用互不重叠的两半被试训练的 decoder，一阶导 90% 可重复，UX 二阶导 65%（logit 37–42%），UU 二阶导只有 42%（logit 20–22%）；可重复的这部分与解析真值仍相差约 90%。
5. **decoder 上做交叉矩：去掉了种子噪声，但不超过原 decoder。** 重训的 decoder 用普通平方是 .706 / .741，换成交叉矩回到 .815 / .788，与原 decoder 的 .817 / .812 持平或略低。
6. **EXP13 的 CR3 成绩对训练样本量敏感。** 只用一半被试（1750）训练的 decoder，冻结损失掉到 .69（p 通道，两个重复一致）。纯噪声二阶场上是 .58–.69，所以 .817 确实来自 decoder 的函数结构；但它不是来自真实的 UU 结构——同一损失放在解析代入场上只有 .69–.70。
7. **副产品：一个完全不用 decoder 的方法接近基线，但不稳定。** 逐题二次 logistic 拟合 + 5 折交叉拟合的 `UUd_share`，在重复 1 / 2 / 3 上平均 MCC .801 / .783 / .801、泄漏 .169 / .198 / .174（EXP13：.817 / .812 / .814，.165 / .183 / .166），最大泄漏 .49–.53；随折的划分波动约 ±.035。达不到 ≥ .03 的判据，不算提升。

**判据**（用户）：CR3 泄漏相对 EXP13 下降 ≥ .03 且各重复都成立。本目录没有任何候选达到。

## 方法

**思想。** EXP13 用同一个函数估计的平方来量 E[(∂²h/∂u_i∂u_k)²]，估计误差被平方后给所有格子加上一层正的底，精确的零因此消失。这里把函数在互不重叠的被试子集上估计 K ≥ 2 次，能量一律取两个不同估计的乘积：

    Ê = mean_{a≠b} H⁽ᵃ⁾ · H⁽ᵇ⁾

误差独立，期望里相互抵消，真零的格子期望为零，不需要扣底，也没有调节常数。

**函数估计的两种来源**
- 逐题多项式（严格 W–Y）：共享题库上每个刺激拟合一个 U 的多项式，输入只有 (V, 题号, 选择)。`lpm2 / lpm3` 是线性概率多项式，`logit2 / logit3` 是逐题 logistic 多项式。系数直接给出一阶载荷和 UU 矩阵，不对任何网络求导，也不假设对 X 光滑。在按经验测度正交化的基上加岭惩罚，等于惩罚 E[(η − 均值)²]，拟合对 U 的任意可逆线性变换严格等变。
- 独立训练的 decoder：冻结 Z，用观测选择训练。x6_plan06 / e06 的 10 个 decoder 共用全部训练被试（只有种子不同）；本目录另训了"两半被试各 5 个种子"的版本，两半之间的误差才是真正独立的。

**矩与损失**（`common/xfit.py`）
- `T4` (d⁴)：合并的 UU 矩，等同 EXP13 的 T4；`SX`：EXP13 的 UX 矩。
- `T4I` (K×d⁴)、`SG`、`SGc`：题目级的 UU、一阶、以及一阶在题目间去均值后的矩（U × 刺激交互）。
- `UUd_share`、`UX_neff`：与 EXP13 定义相同（单元测试核对）。
- `UUI_softL0_k`：对 (题目, i, j) 的 UU 能量做软计数，阈值 k²×平均能量；负的交叉能量按零计。等同 EXP03 的 HUUP·softL0。
- `GI_softL0_k`、`TOT_softL0_k`、`UI_neff`：一阶的题目级支撑计数、一二阶合并、U × 题目交互的有效个数。
- `pool_items`：把题目级矩按只由 X 决定的上下文求平均。无偏的交叉能量在合并时噪声会平均掉，普通平方不会。
- 搜索与 EXP13 完全相同：Haar 200 个旋转（种子 1）标准化，24 起点（种子 7），Adam 250 步 × 0.05。

### 第 0 步：二阶失真的来源（CR3 重复 1，Oracle 轴，`step0_estimand/`）

| 场 | logit：λ / τ 自曲率占比 | p：λ / τ | 与 decoder 的相对距离（logit 通道，调增益后）g / H_UU / H_UX | EXP13 损失在该场上（logit / p 的 MCC） |
|---|---|---|---|---|
| decoder | .773 / .665 | .788 / .676 | — | .831 / .817 |
| 解析代入（无后验噪声） | .141 / .189 | .771 / .563 | .15 / .94 / .79 | .704 / .686 |
| logit 上平均（EXP12 的做法，s = 1） | .143 / .190 | .763 / .575 | .15 / .94 / .79 | .703 / .682 |
| 概率上平均（真正的估计目标，s = 1） | .161 / .220 | .765 / .586 | .15 / .94 / .79 | .700 / .680 |

- 自曲率占比 = RMS(H_ii) / RMS(‖H_i·‖)，EXP05 的定义。解析代入不为 0，是因为线性估计 T 的映射不是正交的。
- EXP12 当时把平均做在 logit 上，这样 τ、λ 的线性按构造保留，所以检验不到这个问题；这里补上了概率尺度的平均。
- 纯噪声二阶场上的 EXP13 损失（`noise_only.py`，3 个种子）：重复 1 为 .675 / .688 / .611，重复 2 为 .689 / .575 / .580；PCA 轴 .722 / .651；不旋转 .573 / .709。

## 如实说明

- 本目录没有产生达到判据的方法。正面的结果只有 Gap 1（解析场）和模拟中的高数据量情形。
- 上面"接近基线"的 `UUd_share` 变体是在重复 1 / 2 的 TEST 上看过多个变体后挑出来的；`wy_uud.py` 的表是事后不挑选地跑全了所有折数和种子，但选择"logit2 + UUd_share"这一步本身用过 TEST。
- "重复 3"是同一 S1 数据集上换训练种子，没有新生成数据集。
- 第 0 步的后验噪声用训练集上 T 对 V 线性回归的残差重采样，是同方差近似。
- e06 的 decoder 共用训练被试，它们之间的交叉矩只去掉了初始化和优化的噪声。
- 数据量模拟在真坐标下做，没有包含 Z 的后验噪声，给出的是下界。
- 题库型设计才能逐题拟合；C1–C3（每人随机刺激）需要对 X 用基函数，本轮未做。
- x6_plan06 / e06（decoder 集成）的代码和结果此前已存在但未提交，其 README 仍标"待做"；本目录只读使用了它缓存的导数场，未改动。
