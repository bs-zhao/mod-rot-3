# Independent metric experiments

Each child directory is a complete, independently runnable experiment with its
own data preparation, definitions, configuration, checks and figures. Experiments
do not import or launch rotation suites or one another. This area evaluates
metrics; it does not silently turn descriptive metric winners into rotations.

The first experiment is [uxy_landscape](uxy_landscape/README.md): supervised
reference-coordinate diagnostics, five fixed response versions, existing saved
rotations, all reference-coordinate planes and a joint rotation path.
