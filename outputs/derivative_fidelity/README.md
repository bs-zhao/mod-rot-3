# Derivative fidelity outputs

This directory is reserved for results generated by
experiments/derivative_fidelity. Code is in that experiments/ folder; datasets,
checkpoints, and previous experiment outputs must not be modified.

Run from the repository root:
python -m experiments.derivative_fidelity.run --models C1 --repeats 1 --channels logit --subjects 8 --stimuli 16 --methods ad_mixed --tag smoke01

All generated result files remain under outputs/derivative_fidelity/<tag>.
They are intentionally excluded from Git commits by the repository's
existing output-ignore policy; no experiments have been executed merely by
committing this placeholder.
