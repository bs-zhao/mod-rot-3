只记录**实际跑出**的数字；全部来自 CR3 的 NP 重复 1 / 2，冻结的 EXP13 损失（p 通道，UX_neff + UUd_share，Haar-200 seed 1，24 起点 seed 7，Adam 250×lr .05）。所有 TEST 已被历史工作查看，属探索性比较。

## EXP20A：样本量（完成 CR3 两个重复；p 为主，logit 为机制对照）
流式计算 5000 被试 × 500 刺激仅需约 43 秒。N 为 TRAIN 嵌套子集（5 个种子）；固定轴尺度（C_ref = 全 TRAIN）：

| N | 重复 1 MCC / 泄漏 / 最大泄漏 / Oracle 角 | 重复 2 MCC / 泄漏 / 最大泄漏 / Oracle 角 |
|---|---|---|
| 100 | .808 / .171 / .400 / 28.3° | .810 / .184 / .378 / 29.9° |
| 300 | .811 / .168 / .399 / 27.9° | .812 / .181 / .372 / 29.8° |
| 1000 | .813 / .165 / .400 / 27.5° | .812 / .181 / .372 / 29.8° |
| 2000 | .814 / .164 / .400 / 27.4° | .812 / .181 / .370 / 29.8° |
| 全 TRAIN | .814 / .164 / .401 / 27.3° | .812 / .181 / .370 / 29.7° |
| 历史 300（A0，原语义） | .817 / .165 / .368 / 26.2° | .812 / .183 / .378 / 28.9° |
| 全 5000（transductive，含 TEST，仅诊断） | .815 / .162 / .401 / 27.2° | .812 / .181 / .371 / 29.8° |

- 矩相对误差与景观 Spearman 随 N 单调收敛（重复 1：SX 误差 .047→.008，Spearman .992→1.000；极小点到全量解的角度 3.6°→0.5°）。
- **MCC、泄漏和与 Oracle 的角度都没有随 N 改善**；A-native / A-fixed 差别 ≤ .003。logit 对照：重复 1 全 TRAIN .824（A0 .831），重复 2 .811，同样不改善。
- 判读：矩 / 景观已收敛而恢复不变 ⇒ **样本估计不是瓶颈，停止增大 N**。

## EXP20B：Gaussian latent 积分（完成 CR3 两个重复，p 通道）
- 积分器（同测度 P1 = N(μ_train, Σ_train)，C_ref = 全 TRAIN）：MC（5 种子）、加扰 Sobol RQMC（5 个 scramble）、GH（m=3,5,7,9）收敛到同一个解（重复 1 MCC .817–.818，重复 2 .812）；RQMC 矩误差约为 MC 的 1/20（8192 节点 SX 误差 .0002 对 .0037）。
- 测度比较（converged RQMC 4×4096 节点，表中 MCC / 泄漏 / 最大泄漏 / Oracle 角）：

| 测度 | 重复 1 | 重复 2 |
|---|---|---|
| P0 经验 TRAIN | .814 / .164 / .401 / 27.3° | .812 / .181 / .370 / 29.7° |
| P1 Gaussian 完整协方差 | .818 / .155 / .402 / 27.2° | .812 / .182 / .371 / 29.6° |
| P2 对角 | .819 / .153 / .405 / 27.1° | .812 / .182 / .372 / 29.7° |
| P3 N(0,I)（原 Z 坐标） | .825 / .152 / .427 / 25.4° | .809 / .185 / .381 / 30.5° |
| P4 球形 | .819 / .153 / .409 / 27.1° | .812 / .182 / .372 / 29.7° |
| P5 截断 95% | .818 / .156 / .404 / 27.0° | .812 / .182 / .372 / 29.7° |
| P6 c=0.5 | **.831** / .144 / .444 / 23.8° | .811 / .182 / .382 / 30.1° |
| P6 c=1.5 | .811 / .165 / .378 / 29.9° | .812 / .184 / .373 / 28.6° |

- TRAIN 潜变量不是 Gaussian：γ 轴偏态 −0.63、超额峰度 0.85；Mahalanobis 尾部比 χ² 重（99% 分位 16.3 对 13.3）；高于 95% 分位的区域贡献约 17% 的 UU 能量、约 12% 的 UX 能量（`results/exp20b_*_diagnostics.json`）。
- 重复 1 中收缩测度（c = 0.5、P3）有小幅提升（MCC .831）但最大泄漏变大（.44）、Oracle 角仍 24°，**在重复 2 不复现**（.811 / .809）。判读：同 P1 内积分器收敛一致，P1 与 P0 差异很小 ⇒ 测度效应微弱、不稳定，不是改善来源；不继续加大节点数。
