## C1–C3 确认（只做了负结果的确认，p 通道，MCC / 泄漏 / 最大泄漏）
- **EXP20A**（历史 300 → 全 TRAIN）：C1 .9688 → .9687（重复 1）、.9689 → .9689（重复 2）；C3 .9600 → .9600、.9615 → .9608；C2 重复 1 .9645 → .9603（泄漏 .060 → .070，最大泄漏 .152 → .209，Oracle 角 10.6°）、重复 2 .9677 → .9673。**样本量增大不提高，C2 重复 1 略变差**，其余持平。
- **EXP22**（σ = 0 / 0.25 / 0.5，A0）：C1、C3 全部在 ±.002 内；C2 重复 1 有改善（σ=0.5 先平均再平方：.9600 → .9655，泄漏 .072 → .056）但**重复 2 反向**（.9675 → .9627，泄漏 .047 → .072）。结果不一致，不能归因于平滑。
- C1–C3 没有运行 EXP20B、EXP21、EXP23。

## 判读（按 doc 07 决策规则）
- 样本数增大使矩与景观收敛而恢复不变 ⇒ 样本估计不是瓶颈；同一测度内 MC / RQMC / GH 一致 ⇒ 不是积分误差；P1 与经验测度差异很小 ⇒ 测度效应微弱且不稳定。
- 平滑与有限差分没有超过 matched autograd；多尺度聚合也没有 ⇒ **微观尺度的曲率噪声不是 CR3 的主要瓶颈**。
- 依据文档的决策树，剩余可能是 **loss 本身（UUd_share 的偏好）或 decoder 的共同结构偏差**（参见 x6_plan06 的 E1：Oracle 处的损失高于找到点 2.3–2.6 个 Haar 标准差，以及 E6：decoder 集成后仍不改善）。尚未检验的是把同一测度 / 平滑思路迁移到由 WY 拟合的 surrogate（严格 WY-only）。
