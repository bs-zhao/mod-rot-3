# 单一 Hessian 指标研究

当前优先级来自用户最新要求：先搞明白大量单一指标；暂停组合与调权。
所有候选在 C1/C2/C3/CR3 使用同一公式、阈值、汇总方式和判定标准。
解析旋转误差沿用当前 6° 筛选线，并保留原始角度，不能把筛选通过写成三鸿沟成功。

## 指标要回答什么

| 对象 | 单指标族 | 需要辨别的结构与盲点 |
|---|---|---|
| H_UX | L1、半范数、软计数、截断、对数、熵 | 偏好少量强交互；带符号平均可能抵消，RMS 保留能量 |
| H_UX | 行/列 top-k 剩余幅度或能量 | 每个 U 或 X 允许 k 条主边；绝对尾部和相对尾部不是同一偏好 |
| H_UU | 对角、非对角、全矩阵的稀疏性 | 旋转可把交互变成自曲率；只压非对角可能选错轴 |
| H_UU | 对角/非对角能量比例 | 区分能量集中位置；全场为零时不可辨识 |
| H_UU | 局部元素或整行的非零支持 | 区分非线性涉及多少条边、多少个 U；阈值预先固定 |
| [H_UU\|H_UX] | 一个矩阵上的单一稀疏/尾部惩罚 | 使用同一可微 W 网格；没有两个 loss 的可调加权和 |
| H_UX 的 X 函数 | 通用一次/二次多项式系数稀疏、算子共同对角化 | 不使用认知模型模板；比较先平均与后平均以检查抵消 |
| ∂_U H_UU | 纯自身、重复下标、混合三阶项 | 检查非线性/交互随 U 的变化；不是一阶传输 |
| 各类矩阵 | signed、RMS、SD、局部、绝对均值、中位数、90/99 分位 | 检查恒定项、抵消、典型行为、尾部少数点的区别 |
| 能量对照 | 总平方能量 | 检查旋转不变性与按轴标准差造成的假信号，标记 control |

C1/C2/C3 的生成 logit 对 T 线性，因此 H_UU 和纯 U 三阶导数严格为零。
这些单项在三模型上的失败是解析不可辨识，不能靠改进 WY inference 修复。
概率输出与 logit 输出的 Hessian 不同，需分别记录，不能互换成功结论。

## 批量否证，再做完整优化

`single_metric_atlas.py` 对单项去重：JD 的零权重无效参数去掉，
局部绝对值 L1 与先求绝对均值再 L1 的完全相同目标只计一次。
阈值和统计量变体单独列出，不把它们称为同样数量的独立科学思想。

四模型复用 h13 的解析数值字段，固定 seed=20261128、4096 原始 TRAIN UU 点、
128×128 TRAIN 乘积网格；只读取字段、协方差和数值域，不读取旧组合的旋转或 loss。
所有二阶及三阶单项共用这套点。计算共享中间张量，不共享或混合目标值。

每对坐标扫描 0–90°，步长 2.5°；另测同一规则的随机完整旋转。
输出 PLANE_COUNTEREXAMPLE、FLAT_PLANE、NEEDS_JOINT_OPTIMIZATION。
随机点低于 identity 只是线索，因为正确轴附近也可能有更好的极小值。
**所有平面无反例仍不等于 G1 通过**；四模型都存活的单项再用 `run.py`
作独立多起点完整旋转优化，通过之后才进入 G2，再通过才做 G3。

本轮不增加任何组合、不调组合权重。旧组合结果保留为历史，不参与单项候选选择。

## 首轮完整优化与 inference 分支

logit 的 314 项中，只有 UX RMS soft003 与 full RMS soft003 在四模型都没有平面反例或平坦方向。
64 起点完整优化后，前者四模型均过 6°，CR3 为约 5.75°；后者 CR3 为约 44.65°，止步 G1。
这两个目标都是单项软稀疏计数，不是 loss 加权组合。

存活单项的明确公式为：先把 H_UX 按候选 U 坐标及 TRAIN 标准差变换，
对每条 U–X 边计算跨评估点的 RMS，除以固定参考尺度 S，得到 v；
再最小化 `mean(v² / (v² + 0.03²))`。S 是原坐标下 UU 与 UX 总平方能量的平方根，
整个旋转搜索中固定。UU 在此只提供参考尺度，不是另一个可调的 loss 分量。
它衡量有多少条跨点持续存在的交互边，避免带符号平均抵消；阈值 0.03 从首轮清单固定，四模型一致。

UX RMS soft003 使用原来固定的通用 E02（degree=3，256 RBF，length=0.5）进入 G2，
CR3 全空间角度约 5.32°，但多个平面最低点 7.5°，最低曲线相关约 0.880，
未过既定 G2 标准；不能因此推进 G3，也不能偷偷修改指标阈值。

按用户规则，保持单指标不变，先检查两条通用 inference 分支：
已有的 degree=2 同分辨率字段；以及完整数值刺激中心（centers=512，实际受唯一 X 数量限制）、
length=1、degree=3、stimulus ridge=1e-7 的光滑 RBF 分支。其余划分与评估点保持不变。
每条最终采用的分支都必须在四模型使用相同规则。文献依据仍为前述核尺度与导数误差研究，
不新增 CR3 解析模板或模型专属变换。

后续数值结果：degree=2 分支仍未过 CR3 G2；完整刺激中心分支把 UX 相对误差从约 0.202
降到约 0.157，最低平面相关提升至约 0.976，但全空间角度 6.068°，且仍有 7.5° 平面最低点，
所以记录 FAILED_G2。进一步把同一核长度增到 1.5 后，全空间角度约 6.621°，也未通过。
这说明小预测误差、改善的 Hessian 误差与最终旋转通过并非等价。没有降低既定 G2 门槛，未运行 G3。

概率尺度的 314 个相同单项已在四模型全部完成筛选，没有四模型共同存活项。
完整对照表和代表性曲线筛选图见 [单指标报告](results/single_metric_study/REPORT.md)。
此轮获得的是一个四模型 G1 通过、目前止步 G2 的单指标，并非最终通用解。
