# 新优化目标：完整微分模块、轴向递推与函数等变约束

本轮不是修改 JointDiag 权重。实现了新的函数结构目标，先通过解析 gate，再用冻结模型实测，并形成一个待独立训练复核的四模型共同候选。主要候选和阈值已冻结于 `FROZEN_DIFFERENTIAL_CANDIDATE_2026-11-06.json`；冻结提交为 `7798a9d`，在 CR3 repeat02 训练结果和参数恢复被查看之前完成。

## 1. 完整微分模块的稀疏描述代价

用冻结 Bernoulli decoder 的自然参数 `eta=logit1-logit0`，不单独使用某个 logit，也不改变预测分布。q 是 TRAIN PCA 加白化坐标，s 是按 FIT 均值、标准差缩放的原始 X。提取精确 AD 张量：

`T[r,s]=d^(r+s) eta / dq^r dX_std^s`，阶数组合为
`(1,0),(2,0),(3,0),(1,1),(1,2),(2,1)`。

既包含轴内平方、立方，也包含混合导数。对称张量用正交对称基打包，保留完整 Frobenius 能量；每个多重指标模块的强度 g 是各 anchor 上的 RMS，乘以 `h^(r+s)/(r!s!)`，h=0.5，再除以所有块共同的、对旋转不变的 Frobenius 范数。

主要目标为 `L_code(A)=sum_m log(1+g_m(A)/tau)`，`tau=0.02/sqrt(M)`；预声明消融为 `L1=sum_m g_m(A)`。这是有限阶的可计算描述代价代理，不声称普适 MDL 或完整符号表达式长度。

为什么有希望：`ab` 在真实坐标下只占一个 Hessian 乘积模块，45°旋转后需要两个纯平方模块。两种都计算代价，因而不会像“只惩罚交互项”那样奖励错误坐标。线性参数函数的纯 latent Hessian 没有方向信息，但 latent–X 混合算子仍能刻画不同刺激依赖。

这里的 X 是数据给定的物理输入坐标。任意旋转物理 X 会改变这个结构先验，不能宣称对所有输入重参数化不变；但没有旧 response-profile 任意通道改写的问题，也没有逐角度重拟合代理。

## 2. 轴向微分递推代价

对每个固定的实际 X，沿轴 i，组成跨被试状态的三列：

`[h D_i eta, h² D_i² eta/2!, h³ D_i³ eta/3!]`。

最小化这些矩阵的最佳秩一近似残差，分母使用完整一/二/三阶 latent 张量的旋转不变能量。它衡量需要多少种状态模式来生成沿轴的导数序列，不要求交互为零。

- `a*b*x`：真实轴的第二导数为零；错误混合产生状态依赖的一阶导数和常数二阶导数，增加模式。
- `a*x^b`：真实轴导数序列满足一阶递推；混合轴通常需要更多状态模式。
- `a+b*x`：所有旋转都只有一阶导数，目标严格平坦。

因此递推目标单独不足以覆盖线性参数 benchmark。实测也不稳定，保留为候选/诊断，不把它与其他项临时加权成“获胜方法”。

## 3. 输出等变的广义 Rayleigh 目标

直接使用实际刺激点上的函数 profile `eta_n` 和 latent 梯度 `G_n`。对于单位方向 v，`g_v=G_n v`。

加性输出角色：

`J_shift(v)=sum_n ||g_v-mean_X(g_v)||² / sum_n ||g_v||²`。

整体增益角色：令 `beta_n=<eta_n,g_v>/<eta_n,eta_n>`，最小化

`J_gain(v)=sum_n ||g_v-beta_n eta_n||²/||eta_n||² / [sum_n ||g_v||²/||eta_n||²]`。

两者都由广义特征值问题求最优方向。分母用该方向实际效应的能量，避免把“几乎不起作用”误判为“具有简单功能”。这是谱问题的数值归一化，不把 AZ=U 的 A 改成非正交映射。

仅当以下固定规则全部满足时保留方向：最小/次小特征值比≤0.2；次小值>1e-6；谱间隙大于两倍 split-half 算子差异；活动能量至少为平均轴能量的0.05。split-half 规则是稳定性启发，不是校准的显著性检验。

不使用参数名称、生成机制标签或刺激区域。所有模型依次测试同样的 shift 和 gain。两个轴都只是预定义的通用函数角色；是否存在由 F 决定。`a*b*x` 的增益方向形成歧义子空间，不应强行提取唯一轴；解析测试覆盖了这个反例。

**统一候选 `equivariant_code`**：固定通过检验的功能方向，在其欧氏正交补上最小化完整微分模块 code。没有方向通过时退回同一模块目标。主候选是 code，L1 是预声明消融，无论 TEST 上谁更好都不更换主候选。

精确定义为：`min L_code(A)`，约束 `A^T A=I` 且已被支持的若干行等于功能方向（符号和轴位置允许变化）。所有模型使用相同的功能字典、检验规则、目标、阈值与优化流程；不存在按模型编号选择 loss。

## 4. 解析 gate、优化和数值检查

三个2维 toy：幂函数、双线性乘法、截距加刺激斜率，完整模块 code/L1 在181点角度扫描中都偏好真实轴。递推在前两者有效，在最后一个上平坦。4维隐藏正交混合 toy 检查搜索能恢复功能角色。

开发中发现近零 RMS 经二阶矩计算会放大浮点消减误差，改用远低于 code floor 的1e-6平滑；这个修正由解析优化测试驱动，不由 benchmark θ 驱动。高阶 toy AD 改成显式嵌套 JVP，避免全 jacfwd 在精确零高阶项上的不稳定。以上开发失败输出保留，正式结果使用修正后的源文件版本。

13项相关测试通过：对称张量旋转、方向约定、嵌套 AD、三类解析 gate、4维隐藏混合、X投影误差的旋转不变性、功能对称/歧义、truth-free loader 及原有数值契约。

`q=W(z-mu), u=Aq`；W 包括 PCA/白化，A 才是正交矩阵。行实现 U=Q A^T。C1/C2/CR3 用4 PCs，C3用6 PCs，原始 latent 均8维。解码保留余维残差 `r=z-mu-W^+q`，逆变换为 `z=mu+W^+A^T u+r`。完整分布数值等价、正交性和一至三阶有限差分检查均执行。

纯模块目标稳定解决了前三个 benchmark 的大部分轴混合，却没有解决 CR3。不是把它包装成共同成功，而是引入了有单独函数证据的功能角色约束。四模型均从同一数据规则中检出一条方向：C1/C2/C3为近似输出平移，CR3为近似整体增益。广义最小残差约为0.0035、0.0114、0.0153、0.1075；各自次小特征值约0.995、0.995、0.984、0.961。

CR3主候选的各参数 r²：alpha=0.582151、lambda_loss=0.741471、gamma=0.578883、tau=0.735900。最弱匹配由0.286573升至0.578883；非匹配平均 r²由0.093808降至0.035804，最大非匹配绝对 r由0.582514降至0.405424。

## 6. 不采纳/不升级的分支

- 完整 local-X Taylor 三阶效应近似：扰动范数0.25时，C1–C3相对误差约0.00033、0.00118、0.00167；CR3约6.26。因此有限阶 jet code 只能称为局部结构代理，不能当作整体函数的精确描述长度。
- 自动尺度校准只用冻结 F，选择使两半 FIT 的 Taylor 相对误差≤1%的最大半径。CR3得到hq=0.5、hx=0.0078125，数值近似改善，但 code 恢复仍约0.479。**尺度修正本身不解决方向识别。**
- 全局X投影仅在X上拟合 eta 和精确latent导数场，不拟合latent多项式。容量用留出X选择，并保留96个外层X。CR3 logit外层R²约0.970，gradient约0.913，但二/三阶仅约0.407/0.048；其恢复目标未通过结构保真检验，不升级为主候选。开发期 raw-residual-channel 版本在读取其 θ 结果前已被改为旋转不变的 isotropic escape 残差成本；旧输出保留并视为开发版本。

这些分支用于区分目标、估计与尺度问题；不会按其 TEST r²从中挑一个“最好方案”。

## 7. 有限幅度、无theta的功能复核

在128个NP TEST被试、64个未用于角色检测的实际刺激上，沿检出方向移动±0.25、±0.5。重新调用完整冻结 decoder，不用Taylor代替函数：

- C1近似平移的非平移残差占变化能量约0.4%。
- C2约1.1%，C3约1.3%。
- CR3近似增益的非增益残差约8.4%–10.3%。

这支持“近似整体功能角色”，不能称为完全纯净的机制轴。这个检查未加载 θ，也未更改候选。

另做256次FIT被试和X的联合bootstrap。四模型的原角色全部256次仍通过同一固定检验；方向对齐中位数约为C1=0.99998、C2=0.99997、C3=0.99991、CR3=0.99715，CR3的5%分位约0.98521。这只评价同一NP下功能方向的估计稳定性，不能代替整个旋转恢复的稳定性，也不是独立训练重复。

所有S5 latent均来自每个被试的全部已观测Y。本研究是对冻结表示的描述性旋转，不是未见trial的预测改善；旋转保持完整原decoder分布不变。

## 8. 独立训练复核协议与当前状态

已启动 CR3 beta=0.0005、repeat02 的新 NP 训练，保持原训练配置和数据/split。新 repeat 产生不同训练 seed；新进程设置 `CUBLAS_WORKSPACE_CONFIG=:4096:8`。全部 method 源码和主要配置的 SHA256 已冻结，不依据 repeat02 的 θ 结果改阈值、换 code/L1、换目标或丢弃该重复。

新训练已完成：实际359 epochs，best epoch=309，训练seed由原342625162变为673791424。原/新NP的TEST reconstruction CE为0.558749/0.559040，预测质量相当。S5重新提取5000×8 all-trial Z；使用同一4维PCA规则、同一固定主候选重新学习A。执行前检查冻结源码SHA256，差异为零。

阶段结论：得到一个按相同规则运行、在现有四模型均值上共同改善，并在新的CR3训练seed中保持收益的候选。它比初轮被否定的 covariance 目标有更强证据，但仍有原CR3的alpha代价、anchor敏感性、残余交叉载荷以及独立新数据验证缺口，不能称为最终解决。所有已有结果和失败均保留在 ignored outputs；方法、配置和研究记录提交 Git。下一步应在新数据与更多训练重复中验证冻结候选，并针对剩余alpha/gamma混合研究更可靠的残余功能复杂度，不能在当前复核结果上追选权重。

## 文献定位

[Hessian Penalty](https://arxiv.org/abs/2008.10599)鼓励对角Hessian，不能直接当作本项目含真实乘积时的成功准则。[Equation learning](https://proceedings.mlr.press/v80/sahoo18a.html)提供稀疏函数表达的背景；本轮实现的是微分模块代理和函数角色约束，不是EQL，也不声称已有普遍可辨识性定理。
